# Crumbelle

**Crumbelle** is a full-stack bakery e-commerce web application that combines an elegant storefront with practical shopping, authentication, and order-management features.

---

## Live Demo

**Live Website:** https://unspined.onrender.com

---

## Features

* Browse bakery products by category
* Detailed product pages with images, pricing, descriptions, and weight
* Live product search with autocomplete suggestions
* Shopping cart with quantity management and order totals
* Favourites / wishlist functionality
* User registration and login
* Email OTP authentication
* Checkout and order placement
* Order-success and order-tracking pages
* Responsive design for desktop and mobile
* Informational pages for FAQs, shipping, returns, privacy, terms, and contact

## Getting Started

### 1. Install dependencies

```bash
npm install
```

### 2. Configure environment variables

Create a `.env` file and add the credentials required by the application, such as:

```env
DATABASE_URL=
SESSION_SECRET=
EMAIL_USER=
EMAIL_PASSWORD=
```

### 3. Start the application

```bash
npm run dev
```

The application will be available at the local development address shown by the server.
